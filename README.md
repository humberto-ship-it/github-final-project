# Simple Interest Calculator

This open source project provides a Bash script that calculates simple interest
from the principal amount, annual rate of interest, and time period entered by
the user.

## Formula

```text
Simple Interest = Principal × Rate × Time / 100
```

## Run the calculator

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

Enter positive numeric values when prompted. The script validates the input and
prints the calculated simple interest.
